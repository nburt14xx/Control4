Roku Bridge

A complete Roku driver: remote and transport, installed channels, a search with posters that plays the chosen title in the right channel, and a list of what you recently launched. It talks to the Roku directly over the network. Nothing is installed on the Roku.

1. Roku side

  1. On the Roku: Settings > System > Advanced system settings > Control by mobile apps > Network access, set to Enabled (or Permissive). The default, Limited, blocks this driver.
  2. Note the Roku's IP address (Settings > Network > About) and give it a DHCP reservation.

2. Composer

  1. Install the driver file named exactly roku_bridge.c4z. Control4 finds the icons by that file name; a renamed copy shows "?" buttons. The Driver File property shows the installed name.
  2. Add Roku Bridge to the room. It replaces the stock Roku driver: remove that one or move it to an unused room.
  3. Connections: bind Video Out and Audio Out to the TV/AVR input the Roku is plugged into.
  4. Properties: set Roku Address. For search, paste a Search API Key (free, from the Authentication guide at docs.movieofthenight.com; the same key works for Shield Bridge) and check Search Country.
  5. Actions > Test Connection, then read the Lua tab. Expect the Roku's name, model and OS, then "control is working". Actions > Test Search lists results with the channel and content id each would launch.
  6. Refresh Navigators.

3. Using it

  • Search (magnifier, or the Search tab): type a show or movie. Results show a poster and which installed channel has it. Tap to play; if several channels have it, choose one. Titles on a channel you have not installed appear under "On channels you can add": choosing one opens that channel's install page on the Roku.
  • Recent: titles you started from Search, newest first. Tap to jump back in; most channels resume where you stopped. The driver cannot see anything started with the Roku's own remote.
  • Channels: every installed channel with its icon.
  • Remote: on-screen keys. The physical remote's arrows, OK, back and transport work too.
  • Room favorites: press and hold (or use the item menu) on a channel, a Recent title, a search result that one channel plays, or a Where to watch option, then Add to Room Favorites. The favorite keeps the deep link, so it still works after the title leaves Recent.
  • Now Playing bar: Instant Replay, Rewind, Play or Pause (whichever applies, from what the Roku reports), Fast Forward, Home and a D-pad button. D-pad swaps the bar to Back, Left, Up, OK, Down, Right, so you can drive the Roku's menus without leaving Now Playing; the last button swaps back. Each touch screen or phone keeps its own mode; selecting the source or launching a title resets it.
  • Now Playing thumbnail: the poster of the title you launched from search, for as long as that channel is on screen. When the Roku moves to another channel it shows that channel's name and icon, and on the home screen "Roku Home", so the picture never shows something that stopped playing. The Roku does not report which title is playing, so a show picked with the Roku's own remote shows its channel, not its poster.

4. If a title opens the channel's home screen

Each channel has its own way of naming a title, and Roku gives no error when the id is not accepted. The driver prints every launch in the Lua tab, for example Roku Bridge: launch Hulu (channel 2285) contentId=... mediaType=series. Send that line to whoever maintains the driver so the rule for that channel can be corrected. The Launch Deep Link command lets you try ids by hand.

5. Programming

CommandWhat it does
Launch ChannelOpens an installed channel.
Launch Deep LinkOpens a content id in a channel, with a media type.
Resume LatestRelaunches the newest entry in Recent.
Send Key / Send TextPresses a Roku key, or types text into the focused field.
Clear Recent / RefreshEmpties the Recent list / re-reads the channel list.

Events: Item Launched, Roku Online, Roku Offline. Variables: LAST_LAUNCHED_TITLE, LAST_LAUNCHED_APP, ACTIVE_APP, ROKU_ONLINE.

7. Troubleshooting

  • Roku Status mentions "Control by mobile apps": change that setting on the Roku (step 1).
  • Roku Status says Offline: check the address and that the controller can reach port 8060.
  • Play and Pause: Roku has one toggle key, so the driver checks what is playing first. A channel that does not report its state gets a plain toggle.
  • Turn on Debug Mode to see every network call in the Lua tab.
