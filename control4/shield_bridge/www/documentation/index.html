Shield Bridge

Shows the NVIDIA Shield's Continue Watching list (Netflix, Prime Video, Disney+, Max, Hulu and every other app that publishes to Android TV's Watch Next row) inside Navigator, and resumes the selected show with one tap. Needs the free Shield Bridge app installed on the Shield.

1. Shield side

  1. Install the Shield Bridge APK on the Shield (sideload with adb or a file manager).
  2. Open it. Press Grant 'TV listings' permission and accept. Press Allow 'Display over other apps' and enable it. If a screen does not open on this device, run from a PC with adb connected to the Shield: 
    adb shell pm grant dev.shieldbridge android.permission.READ_TV_LISTINGS
adb shell appops set dev.shieldbridge SYSTEM_ALERT_WINDOW allow
  3. Press Allow 'Notification access' and turn on Shield Bridge: what's playing, so Now Playing shows whatever is playing, even a show started with the Shield remote. (adb: adb shell cmd notification allow_listener dev.shieldbridge/dev.shieldbridge.MediaListener)
  4. Press Test: read Continue Watching. It should list what has recently been watched on the box.
  5. Note the address shown (for example http://192.168.1.50:8765). Give the Shield a DHCP reservation.

2. Composer

  1. Install the driver file named exactly shield_bridge.c4z (Driver > Add or Update Driver). Control4 finds the driver's icons by that file name: a copy saved as shield_bridge (1).c4z or with a version in its name shows "?" on the Now Playing buttons and a generic device icon. The read-only Driver File property shows the installed name.
  2. Add the Shield Bridge driver to the room that has the Shield.
  3. Connections: Shield Bridge is the room's Shield source.
    • Move the Shield's own driver to an unused room and disconnect its HDMI and audio outputs from the TV/AVR.
    • Bind Shield Bridge Video Out and Audio Out to the TV/AVR input the Shield is plugged into.
    Only Shield Bridge then appears under Watch in the room.
  4. Properties: set Bridge Address. Set Shield Control Device ID to the device ID of the Shield's own driver (hover over it in the project tree): remote and transport buttons are relayed to it. Set API Key only if you turned that on in the app.
  5. Actions > Test Connection and read the Lua output: it reports the app version and whether both permissions are granted.
  6. Refresh Navigators.

3. Using it

  • Watch > Shield Bridge > Continue Watching. Tap a show: the room switches to the Shield and the show resumes where it left off.
  • Press and hold (or use the item menu) > Add to Room Favorites to put a show on the room's home screen.
  • Apps tab opens any installed TV app.
  • Shield Bridge Remote appears as a second Watch device: the standard Control4 remote screen (D-pad, transport, menu, numbers). It feeds Shield Bridge internally, so it needs no connections. Set After Launch to Switch to Remote to land on it after starting a show. Control4 shows no artwork on this screen type; the poster stays on Shield Bridge's Now Playing.
  • Remote and transport buttons, from the physical remote, the Remote tab or the Now Playing bar, are relayed to the Shield Control Device. Home works through the Shield Bridge app itself.
  • Now Playing shows what is actually playing on the Shield (title, artwork, progress), however it was started. Without Notification access, or for an app that reports nothing, it shows the last show launched from Control4. Now Playing Refresh (s) sets how often it checks while selected.
  • Now Playing bar: OK, Play or Pause (whichever applies), Next, Menu and a D-pad button. D-pad swaps the bar to Back, Left, Up, OK, Down, Right, so you can move around the Shield's menus with the poster still on screen; the last button swaps back to playback. Each touch screen or phone keeps its own mode, and selecting the source or launching a show puts the bar back on playback.

Search

Results inside Control4. Tap the magnifier in Shield Bridge and type a show or movie. Results come with posters, filtered to what streams in your Search Country, and each one names which of the Shield's installed apps carries it. Tap a result to play it: if one installed app has it, it opens there straight away; if several do, a Where to watch list lets you choose. If the title is already in Continue Watching, it resumes from that row instead of opening the title page. Titles that only stream on services whose app is not installed are listed under their own heading. The last item of every result list runs the same search on the TV instead.

This needs a free key from the Streaming Availability API (Movie of the Night): sign up via the Authentication guide at docs.movieofthenight.com, paste the key into Search API Key, set Search Country (two letters, e.g. us), then run Actions > Test Search and read the Lua output. Results are cached for ten minutes to save the free quota. Rentals and purchases are hidden unless Search Includes says otherwise.

The Search tab holds a text box: Show results here opens the same poster results (use it if your touch screens do not show the magnifier), and Search on TV runs the Shield's own cross-app search with results on the TV. A Search programming command runs a fixed TV search from a keypad, scene or voice command. None of this changes the room source or power.

4. Programming

CommandWhat it does
Resume LatestRefreshes the list and resumes the most recently watched item. Optional Room parameter selects the source in that room first. Ideal for a keypad button.
Launch ItemLaunches a specific Continue Watching row (list filled from the cached list).
Launch AppOpens an installed TV app.
Launch URLOpens a deep link, e.g. https://www.netflix.com/title/80057281?source=30.
Wake ShieldWake-on-LAN plus a wake request to the app.

Events: Item Launched, Bridge Online, Bridge Offline. Variables: LAST_LAUNCHED_TITLE, LAST_LAUNCHED_APP, BRIDGE_ONLINE.

6. Troubleshooting

  • Bridge Status says Offline: check the address, that the app's service is running (open the app), and that the controller can reach the Shield's port 8765.
  • List is empty: the TV listings permission is not granted, or nothing has been watched since. Check with the app's Test button.
  • Tap does nothing on the Shield: 'Display over other apps' is not granted. Launches only work from the background with it.
  • A show opens on its detail page instead of playing: that app does not follow Google's resume guideline; press Play once.
  • Now Playing buttons show "?" or the device icon is a generic media player: the driver file is not named shield_bridge.c4z. Check the Driver File property, or Test Connection, which says so in the Lua output.
  • Turn on Debug Mode and watch the Lua output for the HTTP traffic.
